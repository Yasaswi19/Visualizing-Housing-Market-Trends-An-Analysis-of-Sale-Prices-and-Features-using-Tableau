# Visualizing-Housing-Market-Trends-An-Analysis-of-Sale-Prices-and-Features-using-Tableau
📌 Project Overview

The project Visualizing Household Trends aims to analyze, process, and visualize housing-related data to identify key patterns and trends.
It involves data cleaning, transformation, dashboard creation, and storytelling using Tableau and a web-based interface.
___________________________________________________________________________________________________________________________________________________________________
🎯 Objective

To analyze household and housing market data.

To create interactive dashboards that reveal trends in pricing, demographics, and other housing metrics.

To support decision-making with data-driven insights for real estate, urban planning, or economic studies.
__________________________________________________________________________________________________________________________________________________________________________
🛠 Tech Stack

Frontend: HTML, CSS, Bootstrap (templates in website/templates/).

Backend: Python (Flask in app.py).

Data Visualization: Tableau (packaged workbook .tfl and Tableau Public links).

Data Processing: Python (data cleaning & transformation in CSV files).

Other Tools: Empathy Mapping, Data Flow Diagram, Requirement Analysis documents.
____________________________________________________________________________________________________________________________________________________________________________
✨ Features

Data Preparation

Cleaning and transformation of raw housing datasets (Cleaned_Transformed_Housing_Data2.csv).

Aggregation of key metrics for visualization (Aggregated_Transformed_Housing_Data2.csv).

Interactive Dashboards

Tableau dashboards with charts, maps, and KPIs (screenshots provided).

Storytelling views to guide users through insights.

Web Interface

Flask-powered website to host project info, dashboards, and insights.

Pages: Home, About, Dashboard, Story.

Documentation

Problem statements, empathy maps, brainstorming ideas.

Requirement analysis (Solution Requirements, Technology Stack).

Project design and solution architecture.

Testing reports for performance and functionality.

Deployment & Demo

Tableau Public links for direct online access.

A live demo link in demo link.pdf.
